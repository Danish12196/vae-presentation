Part 5 · Variational autoencoders

Loss = reconstruction + KL

Loss= ‖x − x̂‖² + KL( N(μ, σ²) ‖ N(0, 1) )

‖x − x̂‖² reconstruction: how far the rebuilt cat is from the input

KL how far the cloud is from N(0, 1). Zero only when μ = 0 and σ = 1
